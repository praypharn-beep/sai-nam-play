## ภาพที่เหมาะกับเกมนี้

- ไฟล์ PNG พื้นหลังโปร่งใส
- ตัวละครหันขวา มุมข้าง
- ทั้งตัวเห็นหัวถึงเท้า
- น้องมอกควรมีกระรอกขาวเกาะไหล่ซ้ายในภาพเดียวกัน
- ไม่ใช้รูปนักเรียนจริงโดยไม่ได้รับอนุญาตจากผู้ปกครอง
- ใช้ตัวละครที่เจนขึ้นใหม่จาก GPT ได้

ตัดพื้นหลังได้ที่ [Photopea](https://www.photopea.com/) แบบที่ irisogli.com สอน
