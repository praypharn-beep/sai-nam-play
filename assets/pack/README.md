# วางชุด 2D Stylized Adventure Game Asset Pack ที่นี่

ซื้อหรือดาวน์โหลดชุดจริงแล้ว แตกไฟล์ทั้งก้อนมาใส่โฟลเดอร์นี้

`game/assets/pack/`

จากนั้นบอกเลขาว่า “วางชุดแล้ว” จะต่อเข้าเกมให้

## ใช้กับเกมสายน้ำจากภูผีปอบ

ใช้เฉพาะชิ้นที่เข้าโลกบ้านวังน้ำมอก

| ของในแพ็ก | ใช้ในเกมเรา | ไม่ใช้ |
|-----------|-------------|--------|
| Ground Tiles, Platforms | พื้นเดิน แท่นกระโดด | |
| Trees, Grass, Rocks | ตกแต่งสวน ห้วย ภู | |
| Fences, Signs, Door | โฮมสเตย์ สวน วัด | |
| Mountains, Sky, Cloud | ชั้นไกล ถ้าเข้ากับภูผีปอบ | ภูสไตล์อื่นที่ชนกับภาพที่เจนแล้ว |
| Health Bar, Inventory | | เกมนี้ไม่มีเลือด ไม่มีกระเป๋าซับซ้อน |
| Dog animations, Bones | | ไม่ใช่ตัวละครหลัก มีกระรอกหมอกแล้ว |
| Crystals, Rune Stones | | ไม่เข้าบทเรียนสิ่งแวดล้อมท้องถิ่น |
| Butterflies, Bubbles, Grass anim | ตกแต่งห้วยได้เล็กน้อย | |

ตัวละครหลักยังเป็นน้องมอก ยายกา สามเณรของเรา  
อย่าทับไฟล์ใน `characters/` และ `backgrounds/`
